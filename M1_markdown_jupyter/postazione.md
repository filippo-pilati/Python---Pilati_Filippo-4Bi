# Esercizio 1 di M1: Scheda della postazione di laboratorio

## *Hardware*
La mia postazione utilizza un PC Windows 11 con processore Intel i5‑4590 a 3.30 GHz.
Il computer dispone di 8 GB di RAM.

## *Periferiche principali*
Sono presenti monitor, tastiera e mouse standard da laboratorio, collegati tramite porte USB.

La macchina include una scheda di rete configurata per accedere ai servizi scolastici e al Jupyter server.

## *Software installato*

Sulla postazione è installato Visual Studio Code versione 1.9x, usato per modificare i file del repository.
Sono presenti anche JDK 17 e Git 2.4x, necessari per compilare i programmi Java e gestire i commit richiesti dal modulo.

Il browser predefinito è Google Chrome configurato con l’account istituzionale.
Sono disponibili strumenti di diagnostica come il Task Manager, utili per monitorare CPU, memoria e GPU durante le attività.

### *Credenziali di accesso ai servizi del corso*
Accedo al repository tramite il mio account GitHub personale associato alla mail scolastica, senza salvare alcuna password nel documento.

Le credenziali permettono di eseguire push e commit dei file richiesti dal modulo.
Per il Jupyter server d’istituto utilizzo le credenziali fornite dalla scuola, che consentono di lavorare nella cartella personale dedicata.
